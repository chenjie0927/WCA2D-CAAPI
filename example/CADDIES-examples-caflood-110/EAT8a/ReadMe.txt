### Attention **(2015 April)** ###

The CADDIES 2D caflood application can only use a single roughness 
value in the entire domain. The EAT8a benchmark problem 
(Néelz and Pender, 2013) requires two roughness values, 
one for the roads and one for the rest of the domain. 
Thus the results of the caflood application will
differ from the one presented in Néelz and Pender (2013).


Néelz, S., Pender, G., 2013. Benchmarking the latest generation of 2D 
	hydraulic modelling packages. Environment Agency, Horison House, 
	Deanery Road, Bristol, BS1 9AH.
